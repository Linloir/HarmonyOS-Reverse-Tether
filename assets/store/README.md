# 应用市场材料

- `app-icon-1024.png`：1024 × 1024 PNG，使用与应用内一致的图案和颜色。
- `description-zh-CN.txt`：简体中文应用介绍，纯文本。
- `tagline-zh-CN.txt`：一句话简介，共 11 个字符。
- `promotional/`：三张 **1920 × 1080、16:9 横版 PNG** 商店宣传图，上传时选择“横向截图”。
- `screenshots/`：生成宣传图时参考的真机界面截图，保留用于核对实际功能与文案。
- `PROMPTS.md`：内置 image_gen 使用的完整提示词。

宣传图分别展示连接准备、连接状态与流量、手动 HTTPS 联网检查。宣传画面由真机截图生成，界面中的连接状态和测量数值来自对应截图；图片中的设备外框与背景为展示设计。

应用名：USB 网络。包名：`com.linloir.hrevtether`。开发者：linloir。
