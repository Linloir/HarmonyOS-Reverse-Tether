USB 网络是一款面向 HarmonyOS 设备的 USB 网络共享工具，让手机或平板通过 USB 使用所连接电脑的互联网连接。

连接 USB、启动电脑端配套服务后，在应用中允许系统 VPN 请求即可使用。你可以随时连接或断开，查看连接状态与发送、接收流量，并手动检查当前网络的 HTTPS 访问情况。连接中断后，应用会自动重试。

主要功能
• 通过 USB 使用电脑网络，无需设备 root 权限。
• 支持 IPv4 TCP、UDP 和 DNS 转发。
• 显示连接状态与流量统计。
• 提供手动互联网连接检查。
• 无需注册账户，无广告；客户端和电脑端服务均提供开源代码。

使用前需要
• 一台可以联网的电脑，安装 HDC 并运行配套转发服务。
• 在 HarmonyOS 设备上开启 USB 调试，并授权所连接的电脑。
• 首次连接时允许系统 VPN 请求。

电脑端服务提供 Windows x64、Linux x64 和 Linux ARM64 版本。下载与使用说明：https://github.com/Linloir/HarmonyOS-Reverse-Tether

本应用是 USB 网络转发工具，需要你自己的电脑提供网络连接。不支持 IPv6、ICMP/ping 或 IPv4 分片重组；不会额外加密原本未加密的流量，也不提供匿名上网功能。请仅连接并授权你信任的电脑。
