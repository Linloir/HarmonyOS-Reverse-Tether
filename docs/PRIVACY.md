# USB 网络隐私政策

更新日期：2026 年 9 月 9 日　生效日期：2026 年 9 月 9 日

本政策适用于 linloir 开发的「USB 网络」（Harmony Reverse Tether，包名 com.linloir.hrevtether）及本项目配套的电脑端转发服务和控制工具。隐私联系邮箱：3145078758@qq.com。

本应用通过 USB 让 HarmonyOS 设备使用所连接电脑的网络。请在使用前阅读本政策，了解网络数据如何在设备和电脑之间处理，以及你可以如何控制这些处理。

## 1. 我们处理哪些信息

本应用不需要注册账户，不包含广告、用户画像或行为统计服务，不主动读取通讯录、照片、短信、麦克风、摄像头、精确位置、广告标识符或硬件唯一标识符。我们不运营接收用户上网流量的远程 VPN 服务器，也不会将你的上网流量上传给开发者。

但是，转发网络需要在设备及所连接的电脑上处理网络数据。不能将上述说明理解为“完全不处理个人信息”或“没有日志”。具体如下。

网络转发：你启动连接并允许系统 VPN 请求后，应用通过系统虚拟网络接口接收路由进入该接口的 IP 数据包，经 USB/HDC 传给电脑端服务，由电脑访问目标网络。处理的信息包括源和目标 IP 地址、端口、协议、DNS 查询以及传输中的数据内容。这些信息可能包含其他应用发送的个人信息。处理的目的仅为完成你请求的网络连接；默认实现不会建立或保存网络数据包内容档案。

连接状态：应用在本地保存当前状态、状态说明、更新时间、重连次数及发送和接收字节数，用于显示连接情况和排查故障。这些记录不用于识别或跟踪用户，也不会自动发送给开发者。

运行日志：应用可能在系统日志中输出连接事件、DNS 配置、错误信息和联网检查结果。电脑端服务默认向终端输出连接建立和关闭、源和目标 IP 地址及端口、协议、DNS 配置和错误等信息。终端、操作系统或你使用的服务管理工具可能保存这些日志。日志可能反映网络活动，请按自己的需要妥善管理。

电脑控制工具：使用配套 HDC 控制工具时，工具会在本地读取所选择设备的 USB 连接标识、连接状态、系统/API 版本和端口转发信息，以识别设备、建立连接和诊断兼容性问题。工具可能在终端显示这些信息，并在电脑上维护运行状态和进程锁。应用本身不会将这些信息上报给开发者。

手动联网检查：只有点击“检查互联网连接”时，应用才会访问 https://www.example.com/，并在请求中加入当前时间戳以避免缓存。目标网站会像处理普通网页请求一样接收出口 IP 地址、请求时间、请求头及该时间戳。检查使用系统当时选择的网络；未连接本应用 VPN 时，也可能使用 WLAN 或移动网络。该网站由第三方运营，其处理适用该网站的规则。此功能可以不使用。

外部工具发起的网络质量探测：应用还提供独立于 VPN 的诊断接口。通过系统应用调用接口（例如已授权的 HDC）收到包含请求标识和 STUN 服务器列表的请求后，应用会解析这些服务器的域名，并通过设备当前网络向每个服务器发送少量 STUN Binding 数据包，计算往返时间和丢包率。未开启 VPN 时也可执行，使用的可能是 WLAN 或移动网络；执行探测不会开启 VPN。应用本身不设置周期探测任务，但调用方可以按其配置定期调用。

STUN 请求包含随机事务标识，不携带账户、通讯录、应用流量内容或硬件标识。服务器运营者会接触到网络出口 IP、端口、请求时间及事务标识；服务器由调用方指定，可能由调用方、开发者或其他第三方提供。请信任调用工具及其选择的服务器。结果包括请求标识、目标服务器、收发数量、往返时间、丢包率及必要错误信息，通过本地结果接口返回给持有该请求标识的调用方。结果短暂保存在内存中，正常返回或请求结束后释放，不写入应用文件；系统可能保留不含数据包内容的完成或错误日志。调用方可能自行保存结果，其保存方式和期限由调用方决定。

隐私咨询：如果你通过邮箱联系我们，我们会处理你的邮箱地址、邮件内容以及你自愿提供的附件，用于答复和处理请求。请勿发送私钥、密码、完整网络流量或与请求无关的敏感信息。收发邮件服务提供商也会为传递和存储邮件处理相应信息。

## 2. 权限与使用选择

网络访问权限（ohos.permission.INTERNET）用于连接本地转发服务、手动联网检查及按请求进行 STUN 探测；网络信息权限（ohos.permission.GET_NETWORK_INFO）用于使用网络、域名解析和 VPN 相关系统能力。应用不通过这些权限构建用户画像。

系统 VPN 授权用于建立虚拟网络接口，并将进入该接口的流量经 USB 转发。首次使用需要你在系统提示中允许；你可以拒绝授权，但无法使用网络共享功能。授权和 VPN 连接状态由 HarmonyOS 管理。

USB 调试及 HDC 授权由设备系统管理，用于与电脑建立 USB 通道。请仅授权你信任的电脑；使用完成后可在系统设置中撤销调试授权。

## 3. 数据去向及第三方

网络路径通常为：设备应用 → 系统 VPN → USB/HDC → 你连接的电脑 → DNS 服务及目标网站或应用服务器。电脑的网络出口会成为相应请求的出口。目标服务和你选择的 DNS 服务会依其自身规则处理请求，相关行为不由本项目控制。

本项目不出售个人信息，也不向广告或分析服务共享网络活动。开发者不会通过本应用集中收集或保存你的上网流量。你主动联系开发者时，开发者会接收相应的联系信息；如果调用方选择开发者提供的 STUN 服务器，其运营者还会接收上述探测所需的网络请求信息。如依法必须响应有权机关的要求，仅在必要范围内处理开发者实际持有的信息。

本政策网页托管于 GitHub Pages。页面本身不设置 Cookie，不包含统计脚本、外部字体或广告；GitHub 为提供网站服务可能处理访问 IP、浏览器及请求日志，具体见 [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。访问政策网页不需要开启 VPN 功能。

应用不会另行将流量集中传输到开发者指定的境外服务器。你访问的网站、选择的 DNS、政策托管及邮件服务可能位于不同国家或地区，相关网络请求和处理位置取决于这些服务，不能理解为所有数据均仅在中国境内处理。

## 4. 保存期限与安全

网络转发使用运行中的内存缓冲区，连接结束或进程退出后相应资源会释放；默认不将数据包内容写入文件。应用本地状态文件会随状态变化覆盖，断开连接不等同于删除该文件，可通过清除应用数据或卸载删除。

应用系统日志和电脑终端日志的保存期限由操作系统、日志工具及你的配置决定，本项目不设统一期限；卸载应用也不保证删除系统或电脑已经保存的日志。开发者收到的联系邮件仅在处理请求、必要后续沟通和履行法定义务所需期间保存，之后删除或作去标识化处理。你也可通过邮箱提出删除请求。

电脑端服务默认仅监听本机回环地址。请保护电脑、USB 调试授权及日志访问权限。该工具不会为原本未加密的应用流量额外提供互联网隧道加密，也不会解密 HTTPS；内容是否加密取决于原应用和目标服务使用的协议。所连接电脑及其网络可能接触未加密的通信内容。本应用不提供匿名上网或隐藏电脑出口 IP 的功能。

如发现与本项目有关且影响个人信息的安全事件，开发者将采取与实际情况相适应的处理措施，并在法律要求时履行通知等义务。

## 5. 你的权利与控制方式

你可以随时在应用中断开连接，停止电脑端服务，或在系统中撤销 VPN 和 USB 调试授权。停止 VPN 后，后续网络是否继续使用其他连接由系统及其他应用决定。

网络质量探测独立于 VPN；仅断开 VPN 不会禁止外部工具再次请求探测。你可以停止调用工具的探测功能、撤销相应 USB 调试授权，或卸载应用来停止该入口的使用。单次探测会在完成或达到时限后结束。

你可以清除应用数据或卸载应用，以删除本地状态；电脑运行状态及日志需在对应电脑上管理。应用不设账户，因此没有账户注销步骤。

如需了解、访问、更正、复制或删除开发者实际持有的个人信息，撤回与联系信息有关的授权，或对本政策提出疑问和投诉，请发送邮件至 [3145078758@qq.com](mailto:3145078758@qq.com)，注明“USB 网络隐私请求”。我们会在收到请求后 15 个工作日内回复，并在必要时以最少信息核实请求人身份；依法无法满足的，会说明原因。撤回不影响撤回前依法进行的处理。对于仅保存在你设备或电脑上的数据，开发者无法远程读取或代为删除，可向你说明本地操作方式。

## 6. 未成年人

本应用不是专门面向儿童的产品。未成年人应在监护人指导下阅读本政策并使用；不满十四周岁者应取得监护人同意。监护人如认为开发者通过联系邮件等方式不当持有未成年人的个人信息，可联系我们处理。

功能或数据处理方式发生变化时，我们会更新本政策并标明日期。涉及处理目的、信息种类、使用方式或用户权利的实质变化，会通过应用内提示或其他适当方式告知；依法需要重新取得同意的，将在相应处理开始前取得同意。
