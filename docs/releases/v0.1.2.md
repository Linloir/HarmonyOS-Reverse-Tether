# USB 网络 v0.1.2

通过 USB，让 HarmonyOS 手机或平板使用所连接电脑的互联网连接。

本版本提供 HarmonyOS 客户端，以及 Windows amd64、Linux amd64 和 Linux arm64 的电脑端转发服务。客户端包名为 `com.linloir.hrevtether`，应用名称为「USB 网络」。

## 功能

- 使用系统 VPN 接口，通过 USB/HDC 转发 IPv4 TCP、UDP 和 DNS。
- 在 App 中连接、断开、查看流量和执行手动 HTTPS 联网检查。
- USB 连接中断后自动重试。
- 独立的 STUN 网络质量探测接口：接受多个服务器，返回 RTT 中位数、丢包率、收发包数及各目标结果。无需启用 VPN，也可在 App 进程未运行时调用。
- Windows 转发服务自动读取系统 DNS；所有平台均可通过 `--dns` 指定上游 IPv4 DNS。
- 无需账户，无广告；客户端与转发服务均提供源码。

## 开始使用

1. 安装客户端；电脑安装 HDC 并解压与系统、架构对应的服务包。
2. 在设备上开启 USB 调试，连接 USB 并授权电脑，使用 `hdc list targets` 查看连接标识。
3. 在电脑终端运行 `harmony-relay`；Windows PowerShell 使用 `./harmony-relay.exe`。
4. 在另一终端执行 `hdc -t SERIAL rport tcp:31417 tcp:31417`，把 `SERIAL` 替换为设备连接标识。
5. 打开「USB 网络」，点击“连接”，允许系统 VPN 请求。

Linux 用户也可使用包内的 `scripts/harmony-tether.py run --serial SERIAL --relay ./harmony-relay` 管理连接。停止时断开 App、移除本次创建的 HDC 转发，并结束电脑端服务。

网络质量探测无需开启 USB 供网：

```bash
python3 scripts/network-probe.py --serial SERIAL \
  --stun stun.cloudflare.com:3478 --stun stun.l.google.com:19302
```

更多用法：[项目 README](https://github.com/Linloir/HarmonyOS-Reverse-Tether#readme) · [探测接口说明](https://github.com/Linloir/HarmonyOS-Reverse-Tether/blob/master/docs/NETWORK_PROBE.md)。

## 验证与限制

转发服务单元测试、STUN 数据包与指标验证、应用构建检查已通过。已在 HarmonyOS 真机验证 USB 网络和独立 STUN 探测，覆盖 VPN 开启、关闭及 App 冷启动。Windows 产物完成交叉构建及可执行文件依赖检查，尚未在 Windows 机器上运行验证。

当前不支持 IPv6、ICMP/ping 或 IPv4 分片重组。网络质量结果只反映到所选服务器的当次测量，不代表带宽。独立诊断受系统组件启动和短时后台执行规则约束；系统可能短暂显示启动窗口。工具不会对原本未加密的应用流量额外加密，也不提供匿名上网功能，请仅连接可信电脑。
