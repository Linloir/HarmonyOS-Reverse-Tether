# USB 网络 v0.1.3

本次更新改善不同 HarmonyOS 系统版本的端口兼容性。客户端包名保持 `com.linloir.hrevtether`，电脑端 relay 协议保持兼容。

## 更新内容

- 手机端默认连接端口调整为 `41417`，电脑端服务继续监听 `31417`。
- 支持通过启动参数指定手机端端口，并在界面重新连接时保留该设置。
- 独立 STUN 探测结果端口调整为 `41418`；配套探测脚本根据应用版本自动选择端口。

## 升级方式

安装新版应用，并更新配套 Python 脚本。现有 v0.1.2 Windows amd64、Linux amd64、Linux arm64 relay 二进制可继续使用。

手动建立 USB 转发时使用：

```bash
hdc -t SERIAL rport tcp:41417 tcp:31417
```

随后在 App 中点击“连接”并允许系统 VPN 请求。需要自定义手机端端口时，使用 `scripts/harmony-tether.py run --serial SERIAL --device-port PORT`；首次连接仍需系统授权。

本版本的 `.hap` 和 `.app` 使用发布 Profile 签名。应用市场提交使用 `.app`，独立安装或分发遵循签名 Profile 对应的渠道。
