# USB 网络 v0.1.3

本次更新改善不同 HarmonyOS 系统版本的 USB 连接兼容性，支持自定义手机端连接端口。客户端包名保持 `com.linloir.hrevtether`。

## 更新内容

- 手机端默认连接端口调整为 `41417`，电脑端服务继续监听 `31417`。
- 支持通过启动参数指定手机端端口，并在界面重新连接时保留该设置。
- 独立 STUN 探测结果端口调整为 `41418`；配套探测脚本根据应用版本自动选择端口。
- 网络质量探测继续支持在 VPN 未连接时运行。

## 电脑端兼容性

本次未修改电脑端 relay 的源码、依赖和构建脚本，无需更新 relay 二进制。现有 v0.1.2 Windows amd64、Linux amd64、Linux arm64 版本可继续使用。

配套 Python 脚本需要更新：旧版连接脚本的默认设备端口为 `31417`，旧版探测脚本也不支持新版结果端口。本次提供单独的工具包，包含新版脚本及使用文档。

## 升级方式

安装新版应用，并从工具包更新配套 Python 脚本。电脑端 relay 继续监听 `31417`。

手动建立 USB 转发时使用：

```bash
hdc -t SERIAL rport tcp:41417 tcp:31417
hdc -t SERIAL shell aa start -b com.linloir.hrevtether -a EntryAbility
hdc -t SERIAL shell aa start -b com.linloir.hrevtether -a EntryAbility --ps command start --ps port 41417
```

首次连接需要允许系统 VPN 请求。Linux 也可使用 `python3 scripts/harmony-tether.py run --serial SERIAL --relay /path/to/harmony-relay --device-port PORT`，由脚本管理连接。Windows 使用电脑端 relay 和上述 HDC 命令；`harmony-tether.py` 的进程管理依赖 Linux/POSIX 文件锁。
