# RevTether 0.2.1

本次更新包含客户端 0.2.0–0.2.1 的变化，配套 relay 版本为 0.2.0。

## 网络与恢复

- 支持 IPv6 TCP、UDP 和 DNS。手机默认关闭 IPv6，主机 `--ipv6 inherit|off|on` 可继承或覆盖手机开关；旧版 relay 保持 IPv4 行为。
- 全局、应用白名单和黑名单控制 VPN 路由。RevTether 自身保留在 VPN 路径内，确保后台检测验证实际供网连接。
- USB/relay 连接断开时保留仍有效的系统 VPN/TUN，仅重连传输通道；配置、IPv6 策略改变或 TUN 失效时才重新建立所需接口。重复故障采用退避。
- 提供配对后的后台状态、配置和 STUN 检测接口；检测核对传输会话与流量增量，不需把客户端拉到前台。旧版前台检测仍通过显式参数使用。

## 应用名单

- 逐个添加、移除包名，校验格式、重复和数量限制。
- 可选择经已授权 USB 读取应用名称和包名，按名称或包名搜索、多选、查看已选项。进入说明页不会读取，点击读取后才产生请求；退出取消，45 秒超时。
- 添加方式和应用列表采用两层原生底部卡片，带系统动画和关闭按钮；完成按钮位于底部，说明文字在按钮上方，键盘弹出时保持可操作。
- 导入失败、超时、旧回复和取消不改变应用名单或 VPN。选择完成后，仍需保存设置才能应用路由。
- 当前签名条件下无法原生枚举全部应用；USB 列表不提供真实图标，界面使用通用标识。见[接口与权限调研](../APPLICATION_CATALOG_RESEARCH.md)。

## 验证范围

客户端开发签名版本已在 HUAWEI ADY-AL10 / HarmonyOS 6.0.1.115 上完成连接、应用分流、后台检测、USB 列表、异常提示及卡片交互测试。Linux ARM64 真机及 Linux AMD64 本地双栈服务通过网络验证；Windows AMD64 已交叉编译，未做 Windows 实机验收。

IPv6 真机验证使用受控 ULA 和 IPv6 DNS 端点，不能据此宣称公网 IPv6 上游可用；其他应用的系统解析器也可能受底层网络地址族影响。后台能力不能保证绕过系统强制停止。详细边界见[协议](../PROTOCOL.md)、[后台运行调研](../BACKGROUND_RESEARCH.md)和[测试说明](../TESTING.md)。

源码整理复用原子文件写入和包名校验，移除未使用的回调、旧辅助代码及误入文档目录的二进制。后续源码整理通过本地测试和编译验证，与此前真机签名包的验证分别记录；构建产物、签名材料、控制令牌和本地测试数据不纳入源码仓库。
